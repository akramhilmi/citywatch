# CityWatch

**CityWatch** is a native Android application that enables citizens to report urban hazards such as potholes, broken streetlights, damaged infrastructure, and other public safety issues directly to local authorities.

The project was developed for **WIA2007 Mobile Application Development** and is aligned with **United Nations Sustainable Development Goal 11: Sustainable Cities and Communities**.

---

## Overview

Traditional hazard reporting systems are often slow, fragmented, and lack transparency. CityWatch aims to simplify the reporting process by allowing users to:

* Capture a photo of a hazard
* Select the hazard location on a map
* Submit a report instantly
* Track the report status
* View community reports in a public feed
* Interact with other users through comments and voting

The goal is to create a faster and more transparent communication channel between citizens and local authorities.

---

## Features

### Authentication

* User registration
* Secure login/logout
* Session persistence
* Role-based access control (Admin/User)

### Hazard Reporting

* Capture or upload hazard photos
* GPS-based location selection
* Hazard categorization
* Description input
* Edit and delete reports

### Community Feed

* View reports submitted by other users
* Upvote/downvote reports
* Comment on reports
* Edit or delete own comments

### Profile & Settings

* Update personal information
* Upload profile photo
* View report history

### Accessibility & Performance

* Material 3 dark mode support
* WCAG-compliant color contrast
* Offline caching using Room
* Reduced backend requests for faster loading
